Bad UI
Hall of Fame

Nine form inputs, each lovingly engineered to be as hostile as possible. Every exhibit works — technically. Below each one is what a sane designer would ship instead.

😤 Frustrations survived: 0/9

Phone number, by rotary dial

#01
drag a hole
to the stop
+91

CrimeTen digits, each requiring a full clockwise drag. Typo? There is no backspace. There was never a backspace.

Do instead: type="tel" with inputmode="numeric" so phones show the number pad, and a country picker.

Volume, set by gravity

#02
Volume: 50%

CrimeYou don’t set the volume. You tilt the beam and negotiate with physics. The ball has momentum. The ball has opinions.

Do instead: a plain slider with visible value, plus step buttons for precise changes.

The shy submit button

#03

CrimeEvery time your cursor gets close, it panics and moves. It gets tired eventually. Probably.

Do instead: buttons stay put. If the form isn’t ready, keep it enabled and explain what’s missing on click.

Date of birth slot machine

#04
01
JAN
1990

CrimeSpin and hope. Tap a reel to stop it — good luck, it’s fast. Feb 31 is accepted. Of course it is.

Do instead: three plain text fields (DD / MM / YYYY). For birthdays, native date pickers are slower than typing.

Name, one letter at a time

#05
A
_

CrimeThe alphabet scrolls past at its own pace. Missed your letter? Wait 26 more. Your name is Zainab? Condolences.

Do instead: a text field. Accept any characters — real names have spaces, hyphens, apostrophes and non-Latin scripts.

Select all squares with vibes

#06

CrimeAmbiguous instructions, secret right answer, infinite retries. You are a robot until proven otherwise.

Do instead: invisible bot checks first; if a challenge is unavoidable, make the criteria objective and offer an audio option.

Terms you must “read”

#07

CrimeCheckbox stays disabled until you scroll to the bottom. Then the text grows. Then the checkbox ticks itself off if you blink.

Do instead: a short plain-language summary up top, the full terms one link away, and a checkbox that just works.

Age, precise to the year

#08
Range: 0 – 250,000 years. Each pixel ≈ 900 years.

CrimeA slider with a quarter-million values and 280 pixels. Getting exactly 29 is a geological event.

Do instead: a number field. Sliders are for approximate values where the exact number doesn’t matter.

Volume, via π

#09
3.
Volume: 3%

CrimeYour volume is whatever two-digit pair of π you’re currently on. Want 50%? That’s 30 clicks away. Keep clicking.

Do instead: honestly, anything. A slider. A knob. Two buttons. Shouting.
